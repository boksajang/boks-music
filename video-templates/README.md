# 영상 템플릿

## 기본 템플릿 (GPU 장면)

기본 37종은 모두 GPU 캔버스 장면입니다(가사 영상 29종, 경음악 영상 25종). 편안한 분위기부터 다크·거친(메탈·록·힙합·클럽), 사랑, 우울한 분위기까지 고를 수 있습니다. 앱 코드(`electron/canvas-scenes/`)로 그리고 하드웨어 H.264로 인코딩하므로 빠르게 렌더링되며, 최대 2160p(4K)까지 지원합니다. 장면마다 고유한 움직임을 가지며 다른 장면과 효과를 공유하지 않습니다.

모든 장면에는 다음이 공통으로 표시됩니다.
- 타이틀 문구: 영상 만들기 창에서 입력하며 영상 위쪽의 타이틀로 표시됩니다. 저장해 다음 영상에도 사용합니다.
- 경음악 영상에서는 가사 대신 곡 목록이 흐르고 현재 곡이 강조됩니다.

곡 사이에는 앨범·제목이 바뀌는 전환이 있습니다. 앨범아트의 대표 색이 장면의 강조색이 되며, 앨범아트가 없는 곡은 제목으로 만든 추상 이미지를 사용합니다.

## 템플릿 정보 파일

각 폴더의 `template.json`은 앱에 들어 있는 GPU 장면 하나의 이름·설명과 지원 범위를 정합니다. 장면 자체는 앱 코드이므로 HTML·CSS로 새 장면을 추가하는 방식은 지원하지 않습니다.

| 항목 | 설명 |
|---|---|
| 폴더 이름·`id` | 같은 이름을 씁니다. 영문 소문자·숫자·하이픈만 사용합니다 |
| `renderer`·`scene` | 항상 `canvas`이며, `scene`은 `electron/canvas-scenes/`에 등록된 장면 ID입니다 |
| `aspects` | 지원 비율입니다 |
| `modes` | 사용할 영상 종류입니다(`vocal` 가사 영상, `instrumental` 경음악 영상). 생략하면 둘 다 지원합니다 |
| `spectra`·`recommendedSpectrum` | 배치에 어울리는 스펙트럼 ID와 기본값입니다 |
| `requiresBackground` | `true`이면 사용자가 배경 사진을 고를 수 있습니다 |
| `maxResolution` | 최대 해상도입니다(2160 이하) |

## 스펙트럼 ID

| 형태 | ID |
| --- | --- |
| 슬림 / 라운드 / 대칭 막대 | `bars`, `round-bars`, `mirror` |
| 디지털 블록 / 도트 / 반사 | `blocks`, `dots`, `reflection` |
| 단선 / 이중 파형 | `wave`, `double-wave` |
| 부드러운 면 / 대칭 면 / 리본 | `area`, `mirror-area`, `ribbon` |
| 원형 막대 / 원형 선 / 이중 링 | `radial-bars`, `ring`, `double-ring` |
| 방사 도트 / 타원 링 | `radial-dots`, `ellipse` |

단색·그라데이션·무지개색은 별도 색상 옵션으로 적용됩니다.
