# 영상 템플릿 추가

영상 만들기의 **템플릿 폴더 열기**로 이 폴더를 엽니다. 기존 템플릿 폴더 하나를 복사하고 아래 항목을 바꾼 뒤 **목록 새로고침**을 누르면 앱 소스를 수정하지 않고 추가됩니다.

1. 폴더 이름과 `template.json`의 `id`를 같은 영문 소문자·숫자·하이픈 이름으로 지정합니다.
2. `name`과 `description`에 선택 화면에서 보여줄 이름과 설명을 적습니다.
3. `aspects`에 지원 비율을 지정합니다: `["16:9", "9:16"]`.
4. `spectra`에 배치에 어울리는 스펙트럼 ID를 지정하고, 그중 하나를 `recommendedSpectrum`으로 정합니다.
5. `requiresBackground`가 `true`이면 사용자가 배경 사진을 고를 수 있습니다.
6. `theme.css`에서 배치·색·글꼴 크기를 수정합니다. 세로 레이아웃도 함께 확인하세요. 외부 파일을 불러오는 `url()`과 `@import`는 허용하지 않습니다.

가사·제목·앨범 이미지·진행바·음악 분석은 공통 장면에서 제공합니다. 각 템플릿은 이 요소의 배치와 표현을 담당합니다. 음악/가사의 개인정보를 외부로 전송하는 템플릿 스크립트는 필요하지 않습니다.

템플릿 오류는 목록 새로고침 시 폴더 이름과 함께 표시됩니다. 원래 템플릿을 수정하기보다 복사본에서 작업하면 쉽게 되돌릴 수 있습니다.

## 스펙트럼 ID

| 형태 | ID |
| --- | --- |
| 슬림 / 라운드 / 대칭 막대 | `bars`, `round-bars`, `mirror` |
| 디지털 블록 / 도트 / 반사 | `blocks`, `dots`, `reflection` |
| 단선 / 이중 파형 | `wave`, `double-wave` |
| 부드러운 면 / 대칭 면 / 리본 | `area`, `mirror-area`, `ribbon` |
| 원형 막대 / 원형 선 / 이중 링 | `radial-bars`, `ring`, `double-ring` |
| 방사 도트 / 타원 링 | `radial-dots`, `ellipse` |

예를 들어 가사 옆에 가로 스펙트럼을 두는 템플릿에는 `"spectra": ["bars", "wave", "area"]`를 지정합니다. 원형 배치에는 `"spectra": ["radial-bars", "ring", "double-ring"]`를 지정할 수 있습니다. 선택 화면과 실제 렌더러 모두 이 목록을 검사합니다. 단색·그라데이션·무지개색은 별도 색상 옵션으로 적용됩니다.

## 레이아웃 수정

공통 요소는 `.scene`(전체 장면), `.art`(앨범 이미지), `.content`(제목과 가사), `h1`(제목), `.lyrics`(가사 영역), `.spectrum`(스펙트럼), `.footer`(제목과 재생시간), `.progress`(진행바)입니다. 세로 화면은 `.portrait`가 추가되므로 `.portrait .art`처럼 따로 배치합니다.

새 폴더의 CSS에는 기존 템플릿 ID에 의존하지 않는 위 클래스 선택자를 사용하세요. 가사 줄의 이동 높이와 타이밍은 공통 렌더러가 계산하므로 `.lyric-line`의 높이는 바꾸지 않는 것이 좋습니다. 영상 만들기 화면에서 가로·세로 미리보기를 각각 확인한 뒤 짧은 곡으로 출력해 확인하세요.

## GPU 템플릿

`cinematic-gpu`처럼 `template.json`에 `"renderer": "canvas"`와 `"scene"`이 있는 템플릿은 앱에 내장된 캔버스 장면을 GPU로 그리고 하드웨어 인코딩합니다. 장면 코드는 앱 소스에 있으므로 이 폴더에서는 HTML 템플릿(`theme.css`)만 새로 추가할 수 있습니다.
