# 영상 템플릿

## 기본 템플릿 (GPU 장면)

기본 21종은 모두 GPU 캔버스 장면입니다(가사 영상 16종, 경음악 영상 17종). 앱 코드(`electron/canvas-scenes/`)로 그리고 하드웨어 H.264로 인코딩하므로 빠르게 렌더링되며, 최대 2160p(4K)까지 지원합니다. 장면마다 고유한 움직임을 가지며 다른 장면과 효과를 공유하지 않습니다.

| ID | 이름 | 움직임 | 영상 종류 |
|---|---|---|---|
| `albumblur` | 앨범 블러 | 흐린 앨범아트 위로 떠 있는 앨범에 유리 반사가 스치고, 궤도선이 흔들립니다 | 가사·경음악 |
| `photo` | 포토 스테이지 | 블라인드 빛이 흐르는 사진이 천천히 다가오고, 앨범에서 CD가 나와 돕니다 | 가사·경음악 |
| `vinyl` | 바이닐 라운지 | 램프 빛줄기 속에서 레코드가 슬리브에서 나와 돌고, 톤암이 내려앉습니다 | 가사·경음악 |
| `paper` | 페이퍼 플레이어 | 종이 위 플레이어 카드, 커버 뒤에서 레코드가 나와 돕니다 | 가사·경음악 |
| `cinematic` | 시네마 플로우 | 필름 그레인과 빛 번짐 속, 카메라가 움직이는 장면 위에 크게 떠오르는 가사 | 가사·경음악 |
| `spectrum` | 사운드 갤러리 | 돌아가는 앨범 원반에서 음악 세기만큼 고리가 퍼지고, 저음에 빛이 커집니다 | 가사·경음악 |
| `tracklist` | 플레이리스트 보드 | 돌아가는 CD와 1번부터 흐르는 곡 목록 | 경음악 |
| `cassette` | 카세트 테이프 | 테이프가 실제로 감기며 릴이 돌고, 곡마다 카세트가 빠졌다 들어갑니다. J-카드에 전체 곡 목록 | 가사·경음악 |
| `crt` | 브라운관 TV | 주사선이 흐르는 둥근 브라운관, 곡이 바뀌면 다이얼이 돌고 채널 노이즈가 지나갑니다 | 가사·경음악 |
| `polaroid` | 폴라로이드 보드 | 곡마다 폴라로이드가 떨어져 코르크보드에 붙고, 메모지에 가사가 쓰입니다 | 가사·경음악 |
| `rainwindow` | 비 오는 창가 | 김 서린 창에 빗방울이 흘러내리고, 손가락으로 닦아낸 자리에 가사가 나타납니다 | 가사·경음악 |
| `water` | 물결 반사 | 수면 위로 떠오른 앨범과 가사가 물결에 일렁이며 비치고, 저음에 파문이 퍼집니다 | 가사·경음악 |
| `phone` | 스마트폰 플레이어 | 기울어진 스마트폰 화면에서 가사가 흐르고, 곡마다 폰이 다른 각도로 돌아섭니다 | 가사·경음악 |
| `neon` | 네온 사인 | 벽돌 벽의 네온 가사가 깜빡이며 켜지고, 젖은 바닥에 일렁이며 비칩니다 | 가사 |
| `kinetic` | 키네틱 타이포 | 굵은 가사 단어가 하나씩 튀어나오고, 줄이 바뀌면 색 블록이 화면을 밀어냅니다 | 가사 |
| `karaoke` | 노래방 | 노래방처럼 두 줄 가사가 번갈아 놓이고, 부르는 만큼 색이 칠해지며 카운트다운 점이 사라집니다 | 가사 |
| `swiss` | 스위스 포스터 | 그리드 포스터의 색 블록이 줄마다 미끄러지고, 큰 가사와 전체 곡 목록이 함께 보입니다 | 가사 |
| `radio` | 빈티지 라디오 | 곡마다 다이얼 위 방송국으로 바늘이 미끄러지고, 매직아이가 음악에 반응합니다 | 경음악 |
| `vumeter` | 스튜디오 콘솔 | VU 미터 바늘이 음악에 맞춰 흔들리고, 곡이 바뀌면 채널 페이더가 교차해 올라갑니다 | 경음악 |
| `coverflow` | 커버 플로우 | 앨범 커버가 늘어선 3D 캐러셀이 곡마다 한 칸씩 미끄러지고, 광택 바닥에 비칩니다 | 경음악 |
| `subway` | 지하철 노선도 | 곡이 역이 되는 노선도 위를 열차가 달리고, 안내 표시기에 이번 곡과 다음 곡이 흐릅니다 | 경음악 |

모든 장면에는 다음이 공통으로 표시됩니다.
- 타이틀 문구: 영상 만들기 창에서 입력하며 영상 위쪽의 타이틀로 표시됩니다. 저장해 다음 영상에도 사용합니다.
- 경음악 영상에서는 가사 대신 곡 목록이 흐르고 현재 곡이 강조됩니다.

곡 사이에는 앨범·제목이 바뀌는 전환이 있습니다. 앨범아트의 대표 색이 장면의 강조색이 되며, 앨범아트가 없는 곡은 제목으로 만든 추상 이미지를 사용합니다.

## 직접 추가하는 HTML 템플릿

영상 만들기의 **템플릿 폴더 열기**로 이 폴더를 엽니다. 새 폴더에 `template.json`과 `theme.css`를 두고 **새로고침**을 누르면, 앱 소스를 수정하지 않고 템플릿이 추가됩니다. HTML 템플릿은 HyperFrames로 렌더링하므로 GPU 장면보다 느립니다.

```json
{
  "schemaVersion": 1,
  "id": "my-template",
  "name": "나의 템플릿",
  "description": "선택 화면에 보일 설명",
  "aspects": ["16:9", "9:16"],
  "modes": ["vocal", "instrumental"],
  "spectra": ["bars", "wave"],
  "recommendedSpectrum": "bars",
  "requiresBackground": false,
  "stylesheet": "theme.css"
}
```

| 항목 | 설명 |
|---|---|
| 폴더 이름·`id` | 같은 이름을 씁니다. 영문 소문자·숫자·하이픈만 사용합니다 |
| `aspects` | 지원 비율입니다 |
| `modes` | 사용할 영상 종류입니다(`vocal` 가사 영상, `instrumental` 경음악 영상). 생략하면 둘 다 지원합니다 |
| `spectra`·`recommendedSpectrum` | 배치에 어울리는 스펙트럼 ID와 기본값입니다 |
| `requiresBackground` | `true`이면 사용자가 배경 사진을 고를 수 있습니다 |
| `theme.css` | 배치·색·글꼴 크기를 정합니다. 외부 파일을 불러오는 `url()`과 `@import`는 쓸 수 없습니다 |

공통 요소는 다음과 같습니다. 세로 화면에는 `.portrait`가 붙으므로 `.portrait .art`처럼 따로 배치합니다.

| 선택자 | 요소 |
|---|---|
| `.scene` | 전체 장면 |
| `.topline .brand` | 타이틀 문구 |
| `.topline .collection` | 영상 이름 |
| `.art` | 앨범 이미지 |
| `.content` | 제목과 가사 |
| `h1` | 제목 |
| `.lyrics` | 가사 영역 |
| `.spectrum` | 스펙트럼 |
| `.footer` | 제목과 재생시간 |
| `.progress` | 진행바 |

템플릿 오류는 새로고침할 때 폴더 이름과 함께 표시됩니다.

## 스펙트럼 ID

| 형태 | ID |
| --- | --- |
| 슬림 / 라운드 / 대칭 막대 | `bars`, `round-bars`, `mirror` |
| 디지털 블록 / 도트 / 반사 | `blocks`, `dots`, `reflection` |
| 단선 / 이중 파형 | `wave`, `double-wave` |
| 부드러운 면 / 대칭 면 / 리본 | `area`, `mirror-area`, `ribbon` |
| 원형 막대 / 원형 선 / 이중 링 | `radial-bars`, `ring`, `double-ring` |
| 방사 도트 / 타원 링 | `radial-dots`, `ellipse` |

단색·그라데이션·무지개색은 별도 색상 옵션으로 적용됩니다.
